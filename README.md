# Gabriel Dantas — Portfolio

Personal portfolio in **Editorial Bento (Obsidian · Crimson · Bone Cream)** built with React 19, TypeScript, Tailwind CSS v4, and Newsreader editorial serif typography.

## Stack

- **UI & Typography:** React 19, Tailwind CSS v4, `@fontsource-variable/newsreader`, `Inter`, `JetBrains Mono`, `lucide-react`
- **Tests & Build:** Vite 6, TypeScript `strict`, Vitest

## Commands

```bash
npm install
npm run dev        # Local development server
npm test           # Content integrity & unit tests
npm run typecheck  # TypeScript check
npm run build      # Production bundle
```
